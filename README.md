This is a frontend-based home design application built using HTML.

📌 About the Project

This project is a basic implementation of a home design app interface. It is not a complete project, but a prototype showcasing the design and user flow.

✨ Features
🔐 Sign In and Sign Up pages
🏡 Home page with design options
🎨 “Design” button to navigate to the design section
📐 Users can choose home structure details such as:
Location
Parking
Number of floors
Other basic preferences

🚧 Project Status

This project is currently incomplete and focuses only on frontend design (HTML). More features and functionality will be added in the future.
